#Smart Restaurant Ordering System
 ##1.Project Title: Smart Restaurant Ordering System. 

###2.Overview of the Project: This project is a simple restaurant ordering application which is built using the Python language. This application helps to order food in a restaurant. Customers can browse the menu, add menu items in the cart with quantities, calculate the bill and GST, etc. 

##3.Features: 
•	Display the menu of the restaurant along with its price.
•	Select the items based on the numbers.
•	Adding multiple quantities of the items in the cart.
•	Validation for preventing invalid entries and invalid quantities. 
•	Generate the final bill which includes subtotal, GST, and grand total closing statement. 

##4.Technologies/tools required: 
•	Python
•	VS Code, or any other Python development environment
•	command prompt, PowerShell, terminal. 

##5. Steps to Install and Run the Project
1.	Install Python on your computer.
-Website to download Python: https://www.python.org/
2.	Save the file containing Python code in your project folder.
3.	Open Command Prompt/PowerShell/Terminal.
4.	Change directory to the project folder in which you have saved the file.
5.	Run the following command:
‘’’bash
Python filename.py
‘’’
‘’’bash
python_Vidyarthi_Project_Code.py
‘’’
6. Instructions for Testing
1.	Start the program.
2.	The restaurant menu will be displayed.
3.	Enter a valid number of the item you would like to order.
4.	Provide the quantity of the ordered item.
5.	Continue this process for multiple orders.
6.	When you have completed all your orders, enter 0 to proceed.

7.Check your bill to make sure everything is correct:
•	Item names are correct.
•	Correct quantities are provided.
•	Subtotal is correct.
•	GST is 5%.
•	Grand total is correct.

Expected Output:
